旧服务环境已删除；0.35 的本轮验证使用单独的兼容测试环境和 [测试锁文件](../tests/fixtures/trackio-0.35.lock)。实测依赖解析成功仍可能发生导入 API 不兼容，具体 huggingface-hub 组合见 [记录指南](recording.md#sdk-与数据库兼容)。训练环境自行管理 SDK；新的 SDK/依赖组合需补充矩阵，不承诺任意版本兼容。后端改变时发布器自动验证上一发布 SDK 和实例声明的 `writer_pythons`，失败不切换。

导航抽查已用修改会话有效期、调整图表布局和升级上游三个任务完成；文档本地链接检查通过。常用入口：会话 `Config` → `Auth.session` → `test_auth`；图表 `Metrics` → `plotLayout` → 浏览器手机断言；上游 `source.json` → `sync_upstream` → `compatibility_gate`。网页 Lens main 更新与 Trackio 正式 tag 同步是两条不同流程。

公开合成样例包含 3 个长名称运行、20 个指标、缺失观测、系统指标、配置/长报告、图片、文件和产物。此前量测手机/桌面首屏分别挂载 2/6 个画布，11 秒内 3 次批量请求，隐藏标签后暂停；这些是样例观测，不是真机性能承诺。轮询事实源是 [hostPolling](../frontend/src/lib/hostPolling.js)。
