# 产品约定

本文描述目标行为，不表示已经实现；实现进展见 [当前状态](status.md)。

Trackio Lens 是独立的 Trackio 前端，复用官方后端，并提供独立的认证与启动适配。
项目简介：An independent Trackio frontend for viewing and comparing experiments on desktop and mobile.

## 查看体验与数据语义

- 继承完整前端及已有功能入口，包括实验列表、配置、指标、比较、报告、媒体和产物。
  在最新版上建立基线后改进，不用简化模板替代完整前端。
- 响应式界面：桌面适合多图排列、配置对照及鼠标键盘操作；手机适合单列图表、触控读数和连续阅读。
  常见 360–430 CSS px 视口无需整体横向滚动，长内容按需展开。
- 筛选、切换、返回、深链接和刷新可预期；加载、空数据、失败及数据更新时间清楚可见。
  用长名称、较多指标和较长报告验证，避免为小屏隐藏必要信息。
- 缺失值不当作零，运行状态有可信来源；平滑与降采样不改写原始数据。
  关注实际数据加载量、图表内存与刷新频率。

- 界面支持简体中文和英文。首次按浏览器语言选择，在登录页或设置页切换并保存到当前浏览器；刷新、退出和普通更新保留选择。翻译只作用于界面消息，实验名、指标键、配置值、报告和日志内容保持原文。

## 访问隔离与程序接入

- 实现单实例登录、退出和会话失效处理，保护实验数据、API、媒体、文件和产物。
  允许匿名的登录页、必要静态资源和最小健康检查应明确列出。
- 本机直连与远程请求执行相同认证，不因 loopback 或客户端可伪造的代理头豁免。
  目标是无凭据的其他普通系统用户，不包含 root 或已控制服务运行账号的进程。
- 认证在服务端执行，与渲染分开。优先在同一进程内包装 Trackio ASGI 应用；
  分进程时使用受权限限制的 Unix socket 或等效隔离，不遗留可读同一数据的匿名 TCP 后端。
- 凭据、会话及实例数据的文件权限不能让其他普通账号绕过认证。
  权限调整限于本实例，保留合法训练流程的访问。
- 保留 Trackio 写入权限边界；write_token 不代替读取认证。
  需要 HTTP 的 SDK/CLI 有明确的程序认证方式，不为兼容调用开放匿名数据接口。
- 妥善保存密码/凭据并处理会话与请求保护。正常构建和服务重启保留有效会话，退出、过期和撤销仍生效。
- 支持安装时设置个人账户，以及网页修改账户密码、本机重置和撤销会话。初始交付文件不是运行配置，程序 token 与登录密码分开保存；程序读写凭据不能管理账户或发布代码。
  注册、多租户和复杂角色体系不在当前范围。

## 版本来源与兼容

- 以最新正式发布版的完整前端和对应后端建立初始基线，记录上游 tag、提交和依赖。
  main 的版本字段不证明它与发布 tag 相同；不直接修改 site-packages。
- 提供可重复的上游更新流程：识别新发布、导入变化、保留本地修改、解决兼容问题并验证。
  上游差异集中在适配边界，未经验证不覆盖本地改动。
- 保留上游 MIT 版权/许可及必要第三方声明，标明独立项目身份。
  数据库模型改造、训练调度和完整后端分叉不作为当前默认范围。

## 训练接入与记录

训练接入以明确授权为前提：训练项目独立管理 SDK 和原始记录；可用实例命令查询本地目的地。C++ 通过版本化 JSONL 和独立记录器写入，重试创建新投影，保留原始步数与原文件，不承诺 SDK 未提供的 exactly-once 语义。后端版本变更必须通过已声明记录端的副本兼容检查。接口和验证边界见 [记录指南](recording.md)。

## 运行入口、缓存与恢复

- 支持域名或 IP＋端口，由部署配置选择监听地址及 HTTP/HTTPS；页面和 API 不硬编码个人地址或代理产品。
- 同源提供构建后的前端和 API，Node 主要用于构建。显式指定端口时，占用应失败而非自动换端口。
- 独立安装提供固定的管理命令、隔离依赖及明确的 Python 来源；服务启停和 enable/disable 分别管理运行与自动启动。安装和更新不使用或改变训练环境。
  部署前检查完整构建，防止错误路径回退到简化模板。
- 发布完整、已验证的构建；HTML 重新验证缓存，静态资源有内容版本，刷新可加载一致的新版本。
  若使用 service worker，同时维护更新策略。前端构建身份与后端版本分别可核对。
- 凭据与会话保存在构建目录外。首次启用应用认证可以要求登录，已有代理认证不自动成为应用会话。
- 升级考虑历史数据及记录端兼容，备份和恢复包含必要的数据状态，不只回退程序。
  失败恢复到满足隔离要求的版本，不能自动退回匿名开放；查看服务更新不停止训练任务。

网页更新使用已配置的可信 Lens 仓库和固定 main 提交。浏览器管理需要会话及 CSRF，仓库变更需当前密码；读取 token 不能管理更新。更新在独立用户服务运行，与 CLI 共用发布与验证逻辑，持久记录进度，意外终止后先核验恢复再允许重试。详见 [更新契约与操作](updates.md)。

公开示例使用可配置参数及合成或可公开数据。实际实验数据、私有日志、秘密和机器专用配置放在仓库外。
